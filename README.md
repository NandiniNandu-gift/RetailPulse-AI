
# RetailPulse AI

AI-powered Retail Analytics and Business Intelligence Platform.

## Project Overview
RetailPulse AI is an end-to-end retail analytics project designed to analyze sales, inventory, suppliers and business performance using data analytics, machine learning and interactive dashboards.

## Technologies Used
- Python
- SQL and MySQL
- Machine Learning
- Power BI
- Tableau
- Streamlit
- Pandas, NumPy

## Key Modules
- Sales Intelligence
- Inventory Intelligence
- Supplier Intelligence
- AI-Based Demand Forecasting
- Data Quality Analysis
- Business Validation
- Interactive Business Dashboards

## Dataset
The project works with six main datasets:
- Sales
- Products
- Stores
- Suppliers
- Purchase Orders
- Inventory

## Dashboard
The Streamlit application provides an interactive interface to explore retail analytics and business insights.

## Project Objective
To convert retail business data into meaningful insights that support better decision-making, inventory planning and demand forecasting.
